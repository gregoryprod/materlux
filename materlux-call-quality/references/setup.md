# Подключение коллеги

Распаковать каталог `materlux-call-quality` в каталог skills своего Codex (обычно `%USERPROFILE%\.codex\skills`). Обновить список навыков/перезапустить приложение, если скилл не виден. Установка сама по себе не запускает обработку.

Потребуются: Python 3.10+; подключённый Google Drive с доступом к таблице и папке; собственный разрешённый входящий вебхук Bitrix24 (profile, user.get, voximplant.statistic.get, disk.file.get, crm.activity.get и чтение crm.activity.call.getTranscript). Проверить фактический доступ, а не только галочки вебхука. Не копировать DPAPI-файлы другого пользователя: они связаны с его Windows-профилем.

Рабочие параметры задаются отдельно и не входят в публичный пакет: URL отчёта, лист сотрудников, лист чек-листа, журнал проверок и папка записей. Получить их у владельца процесса и проверить фактические имена и структуру перед записью.

Задать в окружении процесса `MATERLUX_PORTAL_HOST` (точное имя разрешённого портала без https и пути), `MATERLUX_WEBHOOK` (HTTPS URL входящего вебхука; хранить приватно, не в чате, skill, ZIP или журнале), `MATERLUX_OUTPUT_ROOT` (абсолютная рабочая папка). Скрипты никогда не печатают webhook. Облако и локальная папка не дают одной версии автоматического приоритета.

Перед сбором агент сохраняет в OUTPUT_ROOT файл `Сотрудники_источник.json`: `{"read_at":"ISO UTC timestamp","source_url":"URL таблицы","values":[["Направление","ФИО","","Статус"],...]}`. Фактические строки брать из свежего чтения листа; файл старше двух часов скрипт отклонит. Не включать этот файл с персональными данными в распространяемый пакет.

Команды из scripts (подставить реальную дату и свой Python):

```powershell
python download_calls.py --date 2026-10-09
python collect_transcripts.py 2026-10-09
```

Первая проверка: прочитать profile и список сотрудников, сопоставить ID, проверить доступ к папке и структуре отчёта без внешних изменений. Затем согласованный небольшой пилот: ограничить скачивание `--limit 2`, проверить сохранённые аудио и ссылки. Ограниченный пилот не выдавать за полный день. После проверки один исполнитель запускает полный цикл, включая агентскую оценку.

Для локальной расшифровки установить faster-whisper и его зависимости в собственное окружение, заранее подготовить совместимую CTranslate2-модель medium. `MATERLUX_MODEL_PATH` — абсолютная папка модели. Скрипт использует только локальную модель, не скачивает её и не передаёт записи внешнему сервису. Модель и зависимости не входят в ZIP. Команда: `python transcribe_remaining.py ДАТА --batched --segment-only`. При отсутствии модели/ресурсов этап остаётся незавершённым.

Расписание 08:00 МСК — отдельный этап после успешного пилота коллеги. Для полного цикла нужен запуск агента, а не только Python collector. Работающий/разбуженный компьютер, доступные подключения и один назначенный исполнитель обязательны. Этот пакет не меняет существующее расписание.
