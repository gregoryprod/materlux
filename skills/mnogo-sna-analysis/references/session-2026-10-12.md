## Прямые уточнения Ирины

- При работе с таблицами и расчётами использовать Python.
- В расчётном файле себестоимости читать только видимые листы; неясное соответствие моделей уточнять.
- Нужна **себестоимость с учётом отходов**, а не «расходов» — исправление голосовой расшифровки.
- Доля себестоимости = себестоимость / цена. Перед ценой каждой модели добавить две колонки; исходную цену, блок модели и оформление сохранить. Результат — отдельная копия рядом с исходником.
- Отгрузки связать с заказами по номеру без служебных слов. Количество и сумма — из отгрузок, месяц — по дате отгрузки. Ширина 120 см включительно — первая группа, свыше — вторая.
- Москва + Московская область, Петербург + Ленинградская область — два сегмента, остальные субъекты раздельно. Отсутствующий/неоднозначный адрес — отдельное исключение. Товары кроме матрасов исключить и сообщить.
- Сохранить HTML и отдельную копию отгрузок. Дополнить адреса из отдельной октябрьской выгрузки, сохранив остальные задачи.
- ПЭК: одно место 0,4 × 0,4 × 2 м, 35 кг; сдача в отделении Москвы; получение по адресу; без упаковки, страховки и дополнительных погрузочных работ. Расчёт рулона одинаков для всех исходных ширин.
- Последнее уточнение заменило предложение административных центров: использовать **реальный город/населённый пункт из адреса**. Добавить расходы в **существующий дашборд**. Сам запрос расчёта не разрешает оформление заявки или оплату.

## Что пошло не по плану и что перепроверять

- Формат `NumberFormat` первой попытки прайса не принялся русским Excel. Применён локальный формат; результат сверялся Python. Источники не перезаписывались.
- Экспорт отчёта через библиотеку сохранил числа, но убрал уровни группировки 247 строк. Поэтому добавленные колонки перенесены в копию исходника через Excel; группировка затем сверена. Текстовые пробелы также восстановлены. Excel слегка округлил высоты строк до своей пиксельной сетки; допуск был менее 0,2 pt, это не разрешение на произвольную смену оформления.
- После первого HTML мобильная страница выходила за ширину экрана. Исправлены минимальные ширины блоков. До ПЭК подтверждены Chrome, мобильный вид, CSV и отсутствие JS-ошибок.
- После добавления ПЭК подтверждены численные расчёты и пересчёт на 609 сочетаниях фильтров через исполнение кода с тестовой DOM-моделью. Это **не** повторная визуальная проверка браузером: встроенный браузер заблокировал `file:`. Блокировку не обходили.
- ПЭК снова включил страховку после выбора «Матрасы в рулонах». Проверены отдельные компоненты всех тарифов; для 30 направлений полный итог равен перевозке + доставке + страховке + организации страховки.
- Значок ₽ в выручке дашборда был применён без явной валютной пометки в исходной выгрузке. Независимая проверка должна считать валюту выручки неподтверждённой до прямого уточнения; не переносить это допущение в новую финансовую модель.
