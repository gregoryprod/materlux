# ОКК Materlux

Это скилл для агента Codex с подключённым Google Drive и локальным Python. Он объединяет скрипты сбора с работой агента в Google Sheets; не является автономной программой или расписанием.

При первом запуске прочитай [подключение](references/setup.md). Для обработки прочитай [процесс](references/workflow.md), для оценки — [методику](references/assessment.md). Не считай старую переписку обязательной зависимостью.

Дата по умолчанию — вчера в UTC+3. При явной дате пользователя используй её. Перед каждым запуском перечитай сотрудников и текущие критерии из отчёта. Отбирай все успешные входящие/исходящие от 60 секунд включительно, включая перечисленных неактивных сотрудников. Не расширяй перечень сотрудников самостоятельно.

Завершение: проверены количество звонков, реальные файлы и ссылки, полные тексты, критерии и суммы, строки «Проверка звонков», сохранность прежних данных и соответствие локальной/облачной рабочих версий. Неполный этап явно назови. Оценки по автоматическим текстам предварительные, корпоративного утверждения не подразумевают.

Пакет не содержит доступа к аккаунтам. Пользователь должен иметь право читать звонки и писать в согласованные папки/отчёт. Запуск скилла означает поручение выполнить этот цикл в настроенной области; не означает согласия на расходы, изменение CRM, выдачу прав или подключение нового внешнего транскрибатора.

Один исполнитель на дату и отчёт. Локальный lock не защищает от другого компьютера: до запуска выясни, кто выполняет день; при признаках параллельной записи прекрати изменения. Не редактируй manifest одновременно со скриптом транскрибации. Повторный запуск продолжает по ID звонка, не дублирует файлы и оценки.

Ручной запрос: «Используй $materlux-call-quality: выполни полный цикл за вчера по Москве». Для первой проверки на другом компьютере: «Проверь подключение и сопоставление сотрудников без записи в отчёт, затем покажи план пилота».
