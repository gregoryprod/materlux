# ОКК Materlux

Рабочий скилл Codex: сбор звонков Bitrix24, транскрибация, оценка по предоставленному чек-листу и заполнение отчёта.

Публичная редакция от 13.10.2026. Ссылки на внутренние хранилища, персональные сведения и частные договорённости об оценках исключены. Исходный рабочий пакет сохранён отдельно. Методика не объявляется утверждённым корпоративным стандартом.

## Установка

Скопировать каталог `materlux-call-quality` в каталог skills своего Codex. Настроить собственные разрешённые подключения по [инструкции](references/setup.md). Потребуются Python 3.10+, Google Drive и Bitrix24. Для локальной транскрибации нужны faster-whisper и локальная CTranslate2-модель medium, они не входят в пакет.

## Использование

«Используй $materlux-call-quality: выполни полный цикл за вчера по Москве».

Сначала проверить доступы без записи в отчёт, затем провести ограниченный пилот. Один исполнитель обрабатывает конкретную дату. Это процесс агента, а не автономная программа или расписание. Критерии и пороги предоставляются владельцем процесса.

## Данные и проверка

Ключи, вебхуки, записи, персональные списки, отчёты и модели не входят в Git. Доступ к репозиторию не даёт доступа к CRM и Google Drive. Оценки автоматических текстов предварительные. Публичная редакция требует пилота в окружении коллеги; полный цикл на ней ещё не проверен.
